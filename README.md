# 🎓 Campus Connect 2026

A responsive frontend website for a college fest that allows users to explore events, view schedules, and register online.

---

## 📌 Project Overview

**Campus Connect 2026** is a student-focused web application designed to showcase a college festival. It provides an interactive interface for users to:

* Explore different event categories
* View a 3-day event schedule
* Track event countdown
* Register for events online

This project is built using **HTML, CSS, and JavaScript** and demonstrates core frontend development concepts.

---

## 🚀 Features

* 📱 Responsive Navigation Menu
* 🎯 Event Filtering (Tech, Culture, Sports)
* 📅 Tab-based Schedule (Day 1, Day 2, Day 3)
* ⏳ Live Countdown Timer
* 📝 Registration Form with Validation
* 🎨 Modern UI with animations and clean layout

---

## 🛠️ Tech Stack

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsiveness
* **JavaScript (Vanilla JS)** – Interactivity and dynamic behavior

## 🧠 JavaScript Functionalities

### 1. Navigation Toggle

* Opens/closes mobile menu using `classList.toggle()`

### 2. Event Filtering

* Filters events based on selected category using `data-category`

### 3. Schedule Tabs

* Displays selected day's schedule dynamically

### 4. Countdown Timer

* Calculates remaining time using `Date` object
* Updates every second using `setInterval()`

### 5. Form Validation

* Checks empty fields
* Validates email format
* Displays success/error messages
